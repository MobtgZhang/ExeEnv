# Interpretation and release scope

The package documents an execution audit. CURE is an audited instance, not an established improvement over the baselines. “Correct” denotes a fixed strict reference match. It does not imply that supplied evidence independently supports the scientific answer.

G1 denotes the generator; J1–J3 denote three panel roles other than the generator. Role aliases preserve grouping but do not establish independent training, expertise, or uncorrelated errors. Panel majority votes are automated judgments. Outcome-balanced 24-case sampling is not a prevalence estimate; missing conditions and independent expert validity remain unresolved by voting.

Temporal and pilot rows describe previously executed calls in particular service windows. Reaggregating those rows creates no new prospective experiments. Agreement can skip a harmful finalization but also lose a useful repair. Retention benefits depend on where loss occurs and on dependence between stages. Unknown failed-attempt usage prevents complete billing or intrinsic latency claims.

The package omits private service configuration, concrete generator/panel identifiers, provider envelopes, headers, encrypted or opaque fields, raw error bodies, and restricted supplementary source text. The manuscript retains experimental configuration for scientific transparency. No fresh inference client is supplied; `workflow.run()` exposes caller-owned completion and observation interfaces with no service-specific defaults. It never executes generated code itself.

Primary analysis and saved CURE prompt replay are independently recomputed. Supplementary initial-cohort scoring, semantic votes, and temporal outcomes use released indicators and aggregates. Original supplementary source questions, independent semantic certification, and online tool/inference environments are outside this public reproduction contract. The anonymized package is therefore a scoped public artifact, not a byte-identical archive of all historical experiments.
